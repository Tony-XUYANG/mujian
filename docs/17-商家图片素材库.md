# 商家图片素材库

2026-10-08，商品图片上传从“上传后只能在当前表单使用”扩展为可复用的店铺素材库。入口是「我的 → 我的店铺 → 图片素材」；商品主图、相册、自由规格和属性组合的「从素材库选择」会打开同一套选择窗口。

## 已交付效果

| 场景 | 实际效果 |
| --- | --- |
| 浏览 | 12张一页，显示缩略图、名称、尺寸、文件大小、上传日期 |
| 搜索与筛选 | 支持中文名称搜索；全部、商品使用、订单留存、尚未引用四种范围 |
| 引用提示 | 统计商品数和订单数；同一商品主图/相册/规格重复使用只计一次；包含下架商品、停售规格和已取消订单 |
| 复用 | 商品编辑、相册和规格编辑直接选择并回填草稿；取消选图不关闭父表单，选择不自动保存商品 |
| 管理 | 中文重命名、收起和恢复；收起只隐藏常用列表，不删除文件、不改变商品或订单、不释放上传额度 |
| 失败体验 | 加载失败显示中文原因，可重试；店铺只能查看、修改自己的素材 |
| 手机适配 | 320/390px无横向溢出，素材卡片和选图弹窗可操作 |

## 使用方法

1. 在商品主图、相册或规格中上传图片。即使关闭商品表单，已成功上传的图片仍保存在素材库。
2. 打开「我的店铺 → 图片素材」，按用途或中文名称查找。可把默认名改为“奶油白主图”等容易识别的名称。
3. 回到商品编辑，点「从素材库选择」，点击缩略图即可回填；点击「保存商品/规格/属性组合」后才生效。
4. 暂时不用的图片可收起，在「已收起」中恢复后会重新出现在选择窗口。收起不会删图或释放额度，也不会使旧草稿无法保存。

## 数据与接口

新增 `shop_media_details`，以 `media_id` 为主键关联 `shop_media`，保存可选 `display_name` 和 `archived` 状态。当前代码建表共38张；旧图片无元数据时默认显示“商品图片 #编号”，不需要 ALTER 旧表、移动文件或修改URL。

| 接口 | 约定 |
| --- | --- |
| `GET /api/shop/media/images` | `q` 最多80字；`usage=all/products/orders/unused`；`archived=false/true`；`page` 从0开始，`size` 为1–24，默认12；超出末页返回最后有效页 |
| `PATCH /api/shop/media/images/{id}/name` | `{"name":"奶油白主图"}`，去首尾空白后1–80个UTF-16单元，不允许控制字符 |
| `PUT /api/shop/media/images/{id}/archive` | `{"archived":true}`收起，false恢复；同状态重复提交幂等 |

列表返回 `items/total/page/pages/stats`；条目包含id、url、name、尺寸、字节数、上传时间、收起状态、productCount和orderCount。统计包含店铺累计保留数/字节、近一小时成功上传数及额度上限。按当前 JWT 推导有效店铺，不接收客户端shopId；游客401、未开店403、修改未知或他店素材404，提示为中文。

`ShopMediaLibrary` 在只读事务中执行总数、分页及额度查询，避免一次响应中的多次读取看到不同快照。商品引用采用相关子查询：主图相等、相册 `JSON_CONTAINS` 或规格配图 `EXISTS` 任一命中，即计一个商品；订单按原图片URL统计全部状态。购物车图片来自当前商品/规格，无单独图片快照。订单只返回引用数量，不返回收货人、地址或订单号。

重命名和收起分别只 upsert 自己的字段，并发不会覆盖另一字段。默认名称由读取时生成；旧图片首次修改时才写元数据。原 `ShopMedia` 的上传、文件重编码、店铺行锁、归属验证保持兼容，收起不阻止已有草稿保存或既有URL读取。

前端 `MediaLibrary.tsx` 同时提供管理列表和选择窗口，`CommerceImageField` 集中接入主图/相册/两种规格编辑器。窗口 Portal 到body避免嵌套form，并用高于商品编辑的层级接管Escape与焦点；加载使用AbortController并检查取消状态，防止旧筛选响应覆盖新列表。

## 边界与后续

本轮不含内容审核、版权识别、对象存储/CDN、自动垃圾清理和容量告警。商品图片仍公开读取；归属控制只约束绑定和管理，不等于防盗图。

“尚未引用”按当前数据库计算，不包含浏览器中未保存的草稿；默认名称也不等于商品名称。由于采用可恢复收起，引用变化不会触发文件删除。真正清理前需要事务内复核、延迟删除和审计，保留商品、规格及所有历史订单引用。店铺保留上限仍为500张、每小时60次成功上传，没有做500张/大量订单性能压测或数据恢复演练。

当前素材库已在本地运行，云端本轮尚未更新：当前会话无法操作此前登录的腾讯云网页终端，也没有可用且完成主机身份校验的SSH连接。服务器仍是上一轮上传裁剪版；发布包与接续部署步骤见[部署文档](14-Ubuntu测试服务器部署.md)。支付物流仍为模拟，公网HTTP不能据此确认PWA安装能力。
