## 创新点与验证

| 幕间设计 | 解决的问题 | 当前做法 | 当前边界 |
| --- | --- | --- | --- |
| 为你推荐 | 用户不知道下一部看什么 | 单列推荐卡片显示分类、状态、播放/收藏数据和“因为你喜欢「悬疑」类故事”等理由；登录后行为权重排序，游客热度兜底 | `RecommendationFeed.tsx`、`DramaRepository.recommendations`、`GET /api/recommendations` | 推荐页浏览、换一批、点击播放；接口返回分数和理由 |
| 心情选剧 | 用户不想输入关键词时的选择疲劳 | 选择治愈、反转、爱情或换个活法后按分类筛选并打开播放器 | `main.tsx` 的 `MoodPicker`、`style.css` | 打开“心情选剧”弹窗并选择分类；当前不是 AI 生成内容 |
| 继续观看 | 用户中断后难以找回内容 | 分集进度及最近观看集、定期与切集/关闭补存 | 无跨设备并发进度冲突合并 |
| 透明片源说明 | 避免把测试素材误认为商业短剧 | 播放器显示 Sintel、Blender Foundation 与 CC BY 3.0 署名 | 8 条演示内容共用同一片源，不是版权内容库 |
| 可安装 PWA | 快速体验 App 形态，减少安装门槛 | Web App Manifest、App 壳预缓存、离线片库及移动导航 | 未生成签名 APK/IPA，离线能力不覆盖全部在线业务 |

## 数据表与业务约束

| 数据表 | 作用 | 关键约束 |
| --- | --- | --- |
| `user` | 账号、密码哈希、昵称、角色 | 用户名唯一；角色仅允许 `USER` 或 `ADMIN` |
| `drama` | 短剧标题、封面、简介、视频地址、分类和播放量 | 播放量非负 |
| `user_favorite` | 用户收藏关系 | `(user_id, drama_id)` 联合唯一，用户或短剧删除时级联清理 |
| `user_like` | 用户点赞关系 | `(user_id, drama_id)` 联合唯一，用户或短剧删除时级联清理 |
| `watch_history` | 用户最近观看时间与播放位置 | `(user_id, drama_id)` 联合唯一，进度和时长非负 |
| `drama_comment` | 用户对短剧的评论 | 评论最多 500 字，关联删除时级联清理 |
| `drama_comment_report` | 用户对评论的举报记录 | `(comment_id,user_id)` 联合唯一；原因白名单；状态流转为待处理/已处理/已驳回 |
| `drama_comment_moderation` | 评论可见状态与管理员处理记录 | `VISIBLE/HIDDEN`；隐藏不删除，恢复可重新显示 |
| `user_profile` | 用户头像和主页背景地址 | 用户一对一；上传文件限制大小/图片类型，用户删除时级联清理 |

## 自动验收证据

从项目根目录运行：

```bash
node scripts/verify.mjs
node scripts/verify-sw.mjs
PLAYWRIGHT_MODULE=/path/to/playwright CHROMIUM_PATH=/path/to/chromium node scripts/verify-ui.mjs
```

HTTP 脚本会访问本机运行中的服务并执行 40 项自动检查。覆盖数据库连接、公开列表、注册登录、BCrypt/JWT 行为、管理员权限、短剧 CRUD、资源地址校验、点赞收藏重复与并发、详情续播数据、历史删除、评论、评论举报与审核、视频 Range、首页以及 PWA 资源。Service Worker 脚本检查升级保留下载、App 壳资源预缓存和媒体 Range。浏览器脚本检查完整操作与桌面、390px/320px 布局，并输出 `docs/screenshots/`。HTTP 与浏览器脚本会注册临时验收用户，演示数据库中可见；管理员 CRUD 临时短剧会被清理。

完整构建和启动步骤见 [README.md](../README.md)；验收逻辑见 [verify.mjs](../scripts/verify.mjs)。自动接口验收不替代不同设备和浏览器上的人工视觉检查。

## 建议现场演示顺序

1. 打开发现首页，先看精选首屏、短剧卡片和分类心情选剧。
2. 打开“为你推荐”，展示单列卡片、中文推荐理由，点击“换一批”后直接播放一部短剧。
3. 搜索“雨停”并切换分类，说明内容来自后端查询。
4. 播放几秒后点赞、收藏并发表评论，再暂停保存进度。
5. 打开继续观看和我的收藏，展示进度回访与互动持久化。
6. 介绍 PWA 添加到桌面和离线缓存入口，并说明它不是原生安装包。
7. 使用 `admin` / `Admin123!` 打开内容管理，演示统计和短剧 CRUD。
8. 在播放器评论区提交一条举报，切换管理员进入“评论审核”，分别演示驳回或隐藏；刷新播放器确认隐藏，回到后台恢复后再次确认可见。
9. 最后说明数据库联合唯一约束、管理员权限、BCrypt 密码哈希，以及演示内容和后续规划的边界。
