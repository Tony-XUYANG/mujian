## 1. 目标

交付一个“红果核心体验 + 幕间轻创新”的短剧 App 演示版本：用户打开就能发现内容，点击即可播放，互动和进度可以沉淀，下一次能继续观看；管理员可以维护内容和查看基础运营数据。

## 2. 产品原则

1. 先保证发现、播放、互动、回访的主链路完整，再增加复杂能力。
2. 人决定内容规则、权限和数据模型，AI 只生成可审查的小块样板代码。
3. 任何演示素材、版权、推荐和商业化边界都明确标注，不用功能假象替代真实能力。

## 3. 目标模块

### 用户端 App

- 发现首页：精选、分类、搜索、最新/热门排序。
- 人气榜单：按播放量排序并显示名次。
- 播放器：播放、拖动、点赞、收藏、评论、短剧直达分享和离线缓存。
- 评论治理：登录用户按原因举报评论；管理员查看待处理举报、驳回举报、隐藏评论和恢复评论。
- 追更闭环：更新日历、未来七天/搜索、预约/取消、改期回显、按时发布、站内未读提醒和直接播放新集。
- 分集观剧：任意选集、正倒序、上/下集、自动连播、末集停止、分集进度、倍速记忆、浏览器画中画与按集缓存。
- 我的追剧：独立追剧关系、连载/完结状态、新集与未完集数、筛选/搜索和取消确认。
- 继续观看：历史、进度百分比、最近观看和删除历史。
- 离线片库：查看已缓存短剧、断网播放/拖动、移除缓存。
- 我的：抖音式封面背景、圆形头像、头像/背景预览裁剪与更换、中文昵称编辑、收藏/观看记录 Tab、片单搜索和管理、移除确认、在线状态及直接播放入口。
- 为你推荐：单列沉浸式推荐流；游客按热度和新剧兜底，登录用户按追剧、收藏和观看历史偏好排序，并展示中文推荐理由。
- 心情选剧：按治愈、反转、爱情和换个活法四类标签筛选并直接播放，降低选择疲劳。

### 内容管理

- 管理员登录和角色隔离。
- 内容统计：短剧数、用户数、播放量、收藏数。
- 短剧新增、编辑、删除、搜索。
- 分集新增/编辑/删除、集号唯一、归属校验；总集数和完结完整性校验。
- 发布排期：创建/改期/取消/恢复/立即发布；自动扩展总集数、保留预约和上线提醒；重复发布幂等。
- 封面和视频资源地址校验。

### 平台能力

- BCrypt 密码、8 小时 JWT、无状态鉴权。
- 统一错误响应、参数校验、外键级联。
- PWA manifest、Service Worker 和移动端布局。

## 4. 用户故事

- 游客可以搜索“悬疑”，打开一部短剧并查看评论。
- 用户注册后点赞、收藏，刷新或重新登录仍能看到状态。
- 用户播放到一半退出，下一次从“继续观看”回到历史位置；分享链接可直达同一短剧。
- 用户不想搜索时点击“心情选剧”，直接获得一部可看的故事。
- 管理员新增一部短剧后，发现页可以立即看到；删除后互动关系被清理。
- 用户预约下一集，在“我的预约”查看改期或上线状态；发布后在站内信箱看到提醒，一次点击进入对应分集。
- 管理员排好时间后无需守候；服务重启会补发过期任务。通知只有上线事件，改期/取消暂不单独发送消息。
- 用户举报评论后，管理员在内容管理的评论审核区处理；隐藏评论从用户列表消失，驳回保持显示，恢复可重新显示。
- 手机用户将幕间添加到桌面，首次在线使用后断网重启仍能打开离线片库并拖动已缓存视频。

## 6. 验收标准

- 桌面端和移动端无明显横向溢出，底部导航可用。
- 未登录用户不会调用需要身份的互动接口。
- 普通用户访问后台返回 403，过期 Token 返回 401。
- 重复和并发点赞/收藏最终各只有一条关系。
- 评论、历史和进度可以真实写入并重新读取。
- 首次在线打开后 App 壳 JS/CSS 已预缓存，离线视频支持 Range 拖动；缓存删除不影响其他引用同一媒体的短剧。
- `npm run build`、`mvn -q -DskipTests package`、`node scripts/verify.mjs`、`node scripts/verify-sw.mjs` 和浏览器验收通过。
