# 红果短剧竞品分析

## 1. 分析边界

本文件是基于公开页面和公开应用信息做的产品分析，不代表红果内部实现，也不把第三方页面的宣传文案当作幕间已经拥有的能力。分析目标是提取用户已经熟悉的短剧产品模块，用于确定幕间的演示优先级。

公开参考（2026-09-29 核对）：

- [红果短剧 App Store 官方产品页](https://apps.apple.com/cn/app/id6451407032)：产品介绍列出单列推荐、剧场九宫格、评论、一键追剧、提前预约、任意选集、小窗、倍速，以及电影、小说、听书、漫画和会员等业务。下表只按此公开描述判断，不推测内部实现。

## 2. 竞品能力拆解

| 能力 | 用户价值 | 幕间的实现判断 |
| --- | --- | --- |
| 单列个性化推荐 | 上下滑找剧、降低选择成本 | **已实现基础版**：新增“为你推荐”单列卡片流，登录用户按追剧、收藏和观看历史偏好排序，游客按热度与新剧兜底 |
| 剧场九宫格、分类和热榜 | 按兴趣或热度发现内容 | **部分实现**：分类、卡片网格和播放量榜单；不是九宫格剧场 |
| 竖屏/沉浸式播放 | 适配移动端连续观看 | **部分实现**：移动端播放器和 PWA 独立窗口；目前是横屏单视频素材 |
| 任意选集、全集连看 | 减少手动找下一集的操作 | **已实现**：分集目录、正倒序、上/下集及可关闭的自动连播 |
| 热播、完结/连载状态 | 帮助用户判断内容是否值得追 | **已实现基础版**：连载/完结、总集数、已发布集数和后台完整性校验 |
| 搜索 | 直接定位短剧 | 已实现标题搜索 |
| 播放进度 | 离开后继续观看 | **已实现分集续播**：每集独立进度，重开定位最近观看集和秒数 |
| 一键追剧、点赞和评论 | 表达偏好并参与社区 | **已实现基础版**：追剧独立于收藏，片单显示追剧后发布且尚未开始看的新集；无系统推送 |
| 小窗与倍速播控 | 适应碎片时间和不同节奏 | **已实现 Web 版**：0.75–2倍速及记忆；调用浏览器画中画，依赖平台支持 |
| 免费内容入口 | 低门槛开始使用 | 当前演示内容标记为免费观赏 |
| 移动端 App 体验 | 更适合碎片时间使用 | **部分实现**：可安装 PWA、底部导航和离线片库；不是原生 APK/IPA |
| 提前预约/上线提醒 | 待上架内容上线时回访 | **部分实现**：已上架短剧未来分集预约、更新日历、自动发布与站内提醒；尚无整剧首播预约或系统推送 |
| 小说、听书、漫画、会员 | 扩展内容消费与商业模式 | **未实现**：不属于当前短剧演示内容库 |

## 3. 竞品启发与差异化

竞品已经验证的基本路径是：推荐内容 → 快速播放 → 连续观看 → 互动沉淀 → 回到个人内容。幕间优先实现这条闭环，不把复杂推荐算法或商业化支付伪装成已完成能力。

幕间的差异化创新：

1. **可解释推荐 + 心情选剧**：推荐页展示“因为你喜欢「悬疑」类故事”“正在热播”等理由；心情选剧按治愈、反转、爱情和换个活法筛选分类，减少选择疲劳。
2. **继续观看 + 进度云同步**：播放中约每 15 秒及暂停/结束/关闭时保存，重新打开恢复到上次位置。
3. **剧友评论**：评论与短剧绑定，先做轻互动，再为后续剧集讨论和内容审核留出扩展点。
4. **离线片库 PWA**：添加到桌面后可从离线片库管理手动保存的视频，断网后重启并拖动播放；在线业务仍需网络。
5. **透明内容提示**：演示片源明确标注 Sintel/Blender Foundation/CC BY 3.0，避免把示例素材描述成商业版权内容。

## 4. 暂不照搬的能力

商业版权剧集库、机器学习推荐、广告/会员/付费解锁、弹幕、实时直播、系统推送，都需要内容、运营或基础设施配合。分集及多集连播、规则推荐和可解释理由已交付，演示章节共用示例片源。

## 5. 竞品结论

2026-10-02 版本已补齐分集数据模型、内容状态、追剧回访、预约发布和站内提醒，并落地可解释的规则推荐单列流。本版本的推荐是可审查的业务规则，不把它描述成红果同等规模的机器学习推荐；下一阶段优先考虑整剧首播预约、推荐实验和评论审核。
