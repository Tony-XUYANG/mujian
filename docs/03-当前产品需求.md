# 幕间当前产品需求

## 1. 产品定位

幕间是一个面向碎片时间的短剧浏览与播放 App，当前以可安装 PWA 交付。用户可以浏览精选短片、搜索和分类筛选、打开播放器、点赞收藏、发表评论，并在登录后同步观看进度。管理员在内容管理工作台维护短剧。

当前交付不等于原生 Android/iOS 包。浏览器支持时可以“添加到桌面”，独立窗口打开，并缓存 App 壳；真正 APK/IPA 需要后续 Capacitor 或原生壳、SDK 和签名环境。

## 2. 用户角色

| 角色 | 权限 |
| --- | --- |
| 游客 | 浏览、搜索、分类筛选、榜单、播放、查看评论 |
| 普通用户 | 注册/登录、点赞、收藏、查看我的收藏、同步观看历史、发表评论 |
| 管理员 | 拥有普通用户能力，并可查看统计、增删改查短剧 |

## 3. 页面和流程

### 发现页

首屏展示精选短剧、标题简介、分类和立即观看按钮；下方是短剧网格，支持搜索、分类、最新上架/最多播放排序。心情选剧按钮从当前片库中挑一部并打开播放器。

### 榜单页

按播放量展示人气短剧和名次，点击卡片进入播放器。

### 播放器

支持本地视频播放、拖动、播放计数、点赞/取消点赞、收藏/取消收藏、分享短剧直达链接、离线缓存、查看评论和发表评论。登录用户在播放中约每 15 秒以及暂停、结束、关闭时保存进度，重开详情后定位到上次位置。

### 继续观看

展示登录用户的观看记录、进度百分比和最近观看时间。卡片可以直接回到上次位置；可删除某条历史。

### 离线片库

播放器完成缓存后，顶栏下载入口显示已保存条数。离线片库列出本机可用的短剧，断网重启后仍可播放和拖动；可按条目删除。共用同一视频的演示内容只在最后一个引用删除时移除媒体缓存。浏览器清理站点数据或存储回收后，缓存不保证继续存在。

### 我的

展示账号、在线状态、观看记录入口、收藏入口、安装 App 入口、进度同步状态和心情选剧说明。

### 管理后台

管理员登录后看到内容管理入口，查看实时统计和短剧表格，可新增、编辑、删除、搜索短剧。资源地址只允许 `http/https` 或安全的 `/media/` 本地路径。

## 4. 业务规则

- 用户名为 3–24 位字母、数字或下划线，密码长度 8–64 位。
- 密码使用 BCrypt；登录 Token 有效期 8 小时。
- 普通注册请求不能自选管理员角色。
- 点赞和收藏对同一用户/短剧组合幂等，数据库联合唯一约束兜底。
- 评论不能为空，最多 500 字；游客可以看评论，登录用户才能发布。
- 观看进度不超过总时长，服务端再次裁剪进度值。
- 删除短剧级联清理点赞、收藏、观看历史和评论。

## 5. 当前范围验收

构建、启动后，`node scripts/verify.mjs` 应通过 36 项检查；`node scripts/verify-sw.mjs` 检查 App 壳升级和缓存视频 Range；`node scripts/verify-ui.mjs` 在浏览器验证续播、深链接、离线播放和手机布局。当前示例内容共 8 条，视频使用 Sintel Trailer 验证播放，不代表商业短剧内容库。

## 6. 当前非目标

分集和全集连播、视频上传转码、推荐算法、广告和支付、消息推送、弹幕、完整内容审核、原生 APK/IPA 均不属于当前交付。
